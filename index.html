Overview

Cold_Calling_Agent packages a working cold-calling voice product and a portfolio presentation. The interactive app lives under web/ (Vercel). This site is the recruiter-facing GitHub Pages case study with the same figures as the README.

It demonstrates production voice patterns: VAPI orchestration, Deepgram STT, Groq Llama 3.3, Elliot TTS, hybrid call history, and a free permanent recording archive that survives provider retention.

Setup

Local run for reviewers with Node 20+.

bash
git clone https://github.com/rohaan2802/Cold_Calling_Agent.git
cd Cold_Calling_Agent
copy .env.example .env
cd web && npm install && npm run dev

Windows: use RUN.cmd. Vercel Root Directory must be web. Point VAPI webhook to /api/webhook.

Demo

  1. Open the live demo.
  2. Pick English or Urdu → start Call Agent → allow mic.
  3. End call → Call History → optional Pull → Refresh for (A).
  4. Open a recording → play → rename (GitHub-backed on Vercel).
  5. Optional: try Outbound with a US +1 number if credits allow.

Limitations & Troubleshooting

  • VAPI wallet credits are not daily-renewing; free US numbers cap outbound attempts/day.
  • Elliot TTS is English-first; Urdu uses Roman Urdu (Latin script).
  • Vercel FS is read-only — rename/delete need GitHub tokens.
  • GitHub Pages is the portfolio site; the product runs on Vercel.
SymptomLikely fix
Call Agent won’t startCheck NEXT_PUBLIC_VAPI_* + mic permission
Stuck on (V)Pull / webhook Action + VAPI_API_KEY secret
Rename fails on VercelSet GITHUB_TOKEN + GITHUB_REPO
Outbound rejectedDaily free-number limit or missing phone id
